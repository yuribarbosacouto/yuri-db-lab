# Security Policy

Yuri DB Lab is a learning-oriented database engine. Do not use it for production data.

## Reporting

If you find a security issue, open a private security advisory on GitHub or contact the maintainer through the profile links.

## Supported versions

Only the default branch is supported while the project is pre-1.0.

## Scope

Security automation is enabled through GitHub CodeQL and Dependabot. The current engine does not provide authentication, encryption, network isolation, or production-grade crash recovery.
