Yuri DB Lab

A from-scratch database systems lab with SQL parsing, slotted pages, heap storage, WAL, primary and secondary indexes, query plans, automatic WAL recovery, page checksums, CLI workflows, benchmarks, tests, and open-source project hygiene.

npm install && npm run build node apps/cli/dist/index.js shell --dir .ydb npm run bench -- --rows 1000

Systems Core

  • 4KB slotted pages
  • File-backed heap storage
  • JSONL write-ahead log
  • B+Tree indexes
  • Startup WAL recovery
  • Page checksums

Developer Workflow
